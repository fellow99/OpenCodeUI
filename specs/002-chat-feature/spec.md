# 聊天界面模块规范

> **模块路径**: `src/features/chat/`
> **版本**: 1.0
> **状态**: 已实现

---

## 1. 模块概述

聊天界面是 OpenCodeUI 的核心用户交互面，承载用户与 AI 助手之间的全部对话活动。该模块提供完整的消息收发、流式响应展示、权限确认、问题回答、模型选择、会话管理、分屏布局以及侧边栏导航等功能。

模块采用 **Pane（窗格）** 作为基本渲染单元，支持单窗格与多窗格分屏两种布局模式。每个窗格独立维护自身的会话状态、模型选择、消息历史和交互上下文。

### 1.1 设计目标

- 提供流畅的对话体验，支持实时流式消息渲染
- 允许 AI 在执行敏感操作前向用户请求权限确认
- 支持多会话并行，通过分屏同时查看多个对话
- 适配桌面端与移动端，响应式布局自动切换交互模式
- 提供完善的会话管理：搜索、分组、批量操作、活跃状态追踪

### 1.2 模块边界

| 职责                                         | 归属                      |
| -------------------------------------------- | ------------------------- |
| 消息渲染（Markdown、代码高亮、工具调用展示） | `features/message/`       |
| 会话数据拉取与分页                           | `features/sessions/`      |
| @ 提及菜单                                   | `features/mention/`       |
| / 斜杠命令菜单                               | `features/slash-command/` |
| 附件预览                                     | `features/attachment/`    |
| 聊天界面编排与交互                           | **本模块**                |

## 2. 用户故事

### US-01 发送消息与接收流式响应

作为用户，我希望在输入框中输入文本、附加文件或引用文件后发送给 AI，并实时看到 AI 的流式回复，以便快速获得反馈。

### US-02 选择 AI 模型

作为用户，我希望在发送消息前选择使用的 AI 模型和变体（如深度思考模式），以便根据任务需求调整 AI 的能力。

### US-03 处理权限请求

作为用户，当 AI 需要执行文件编辑、命令执行等敏感操作时，我希望看到详细的权限请求信息（包括文件差异预览），并能够选择"允许一次"、"始终允许"或"拒绝"。

### US-04 回答 AI 提问

作为用户，当 AI 向我提出选择题或开放性问题时，我希望能够从预设选项中选择或输入自定义答案，以便引导 AI 的后续行为。

### US-05 管理会话

作为用户，我希望通过侧边栏浏览、搜索、重命名和删除历史会话，并能够按项目/目录分组查看。

### US-06 分享会话

作为用户，我希望生成当前会话的公开分享链接，以便与他人协作或展示对话内容。

### US-07 分屏多任务

作为用户，我希望将聊天界面拆分为多个窗格，同时与不同会话或不同目录进行对话，并通过拖拽交换窗格位置。

### US-08 追踪活跃会话

作为用户，我希望在侧边栏的"活跃"标签页中查看所有正在工作的会话及其状态（工作中、等待权限、等待回答、重试中），以便及时响应 AI 的请求。

### US-09 切换项目/工作目录

作为用户，我希望在侧边栏中快速切换当前工作目录，并为不同目录添加项目分组，以便组织和管理多个代码库的对话。

### US-10 监控上下文使用量

作为用户，我希望在侧边栏底部看到当前会话的上下文窗口使用情况和费用统计，以便了解对话的资源消耗。

## 3. 功能需求

### FR-01 消息输入

| 属性   | 描述           |
| ------ | -------------- |
| 标识   | FR-01          |
| 名称   | 消息输入与发送 |
| 优先级 | P0             |

**描述**: 用户通过多行文本输入框发送消息，支持以下能力：

- **富文本输入**: 自动调整高度的文本区域，支持多行输入
- **文件附件**: 根据所选模型的能力，支持附加图片、PDF、音频、视频文件；支持拖拽文件到输入框
- **@ 提及**: 输入 `@` 触发文件/文件夹/Agent 选择菜单，支持键盘导航和文件夹层级浏览（右箭头进入、左箭头返回上级）
- **/ 斜杠命令**: 输入 `/` 触发命令菜单，支持前端命令（如新建会话）和后端命令
- **Agent 切换**: 在输入框工具栏中选择不同的 Agent（如 build、plan 等）
- **模型变体**: 选择模型的变体模式（如深度思考）
- **历史导航**: 通过上下箭头键浏览发送历史，类似终端体验
- **快捷键发送**: 可配置的发送快捷键
- **撤销/重做**: 支持消息回退后的文本恢复和重做操作
- **移动端收起**: 在移动端滚动时输入框可收起为胶囊，点击展开

**验收标准**:

- 输入框高度随内容自动增长，不超过视口 35%（桌面）或计算上限（移动）
- 提及菜单和命令菜单支持键盘上下导航、Enter/Tab 确认、Esc 关闭
- 拖拽文件到输入框时显示高亮覆盖层提示
- 发送后输入框清空并聚焦

### FR-02 流式响应展示

| 属性   | 描述         |
| ------ | ------------ |
| 标识   | FR-02        |
| 名称   | 流式消息渲染 |
| 优先级 | P0           |

**描述**: 聊天区域实时展示 AI 的流式响应消息：

- **底部锚定**: 新消息到达时自动滚动到底部，用户向上滚动时停止自动跟随
- **历史加载**: 滚动到顶部时自动加载更多历史消息，使用 IntersectionObserver 触发
- **消息分组**: 连续的助手消息合并渲染，形成连贯的回复流
- **可见性追踪**: 通过 IntersectionObserver 追踪当前视口内的消息 ID，用于大纲导航
- **虚拟渲染优化**: 远离视口的消息仅保留占位高度，不渲染实际内容
- **加载状态**: 会话初始加载时显示加载动画，历史加载更多时显示"加载中"提示
- **重试状态**: 连接重试时显示内联状态条，包含倒计时和可展开的错误详情

**验收标准**:

- 新消息到达时，若用户已在底部则自动跟随，否则不打断用户滚动
- 加载历史消息时滚动位置不发生跳动
- 长会话中仅渲染视口附近的消息，保证滚动流畅

### FR-03 权限请求处理

| 属性   | 描述         |
| ------ | ------------ |
| 标识   | FR-03        |
| 名称   | 权限确认交互 |
| 优先级 | P0           |

**描述**: 当 AI 需要执行敏感操作时，向用户展示权限请求：

- **弹窗模式**: 在输入框上方弹出权限确认面板，显示权限类型、请求内容、文件差异预览
- **内嵌模式**: 权限请求直接嵌入消息流中，与工具调用结果相邻渲染
- **操作选项**: 允许一次、始终允许（保存到自动批准规则）、拒绝
- **队列管理**: 多个权限请求排队处理，显示剩余数量；收起时显示胶囊提示
- **子会话标识**: 来自子 Agent 的权限请求显示来源会话名称
- **自动批准**: 支持全局/会话级自动批准规则，匹配后自动通过

**验收标准**:

- 文件编辑类权限请求展示 diff 预览
- 权限请求队列不为空时，输入框上方始终显示最前端的请求
- 收起状态下点击胶囊可重新展开

### FR-04 问题回答

| 属性   | 描述        |
| ------ | ----------- |
| 标识   | FR-04       |
| 名称   | AI 提问交互 |
| 优先级 | P0          |

**描述**: 当 AI 向用户提出问题时，展示问题面板：

- **单选/多选**: 每个问题支持单选或多选模式
- **预设选项**: 展示 AI 提供的选项列表，每个选项可附带描述
- **自定义输入**: 每个问题支持自定义文本输入，可与预设选项组合（多选模式）
- **弹窗/内嵌**: 与权限请求相同，支持弹窗和内嵌两种展示模式
- **提交校验**: 所有问题均有有效答案时才允许提交

**验收标准**:

- 选择自定义输入时自动聚焦文本框
- 单选模式下选择预设选项自动取消自定义输入
- 多选模式下可同时选择多个选项和自定义值

### FR-06 会话分享

| 属性   | 描述           |
| ------ | -------------- |
| 标识   | FR-06          |
| 名称   | 会话分享与导出 |

**描述**: 用户可以为当前会话创建公开分享链接：

### FR-07 分屏布局

| 属性   | 描述       |
| ------ | ---------- |
| 标识   | FR-07      |
| 名称   | 多窗格分屏 |
| 优先级 | P1         |

**描述**: 支持将聊天界面拆分为多个独立窗格：

- **水平/垂直拆分**: 支持水平和垂直两个方向的拆分
- **拖拽调整**: 拖拽分隔线调整窗格比例，使用 requestAnimationFrame 节流保证流畅
- **拖拽交换**: 通过拖拽窗格头部交换两个窗格的内容
- **全屏模式**: 单个窗格可进入全屏，其他窗格隐藏但保持状态
- **紧凑头部**: 分屏模式下每个窗格使用紧凑头部（PaneHeader），显示会话标题和操作按钮
- **最小比例限制**: 防止窗格被压缩到不可用（最小 10%，最大 90%）
- **触摸设备限制**: 触摸设备仅在屏幕宽度 >= 900px 且横屏时允许分屏

**验收标准**:

- 拖拽分隔线时窗格比例实时更新，松开后持久化
- 全屏模式下切换回分屏时恢复原有布局
- 关闭最后一个窗格时自动回到单窗格模式

### FR-08 侧边栏导航

| 属性   | 描述             |
| ------ | ---------------- |
| 标识   | FR-08            |
| 名称   | 侧边栏与会话管理 |
| 优先级 | P0               |

**描述**: 侧边栏提供会话浏览和管理功能：

- **双标签页**: "最近"标签展示按项目分组的会话列表，"活跃"标签展示正在工作的会话
- **项目分组**: 会话按工作目录/项目分组，支持 Git 仓库自动识别根目录
- **工作区树**: Git 项目下按工作区子目录进一步分组
- **搜索过滤**: 支持按会话标题搜索
- **会话操作**: 重命名、删除、批量删除（编辑模式）
- **项目操作**: 添加项目、移除项目、拖拽排序、批量移除
- **子会话展示**: 支持展开查看父会话下的子 Agent 会话
- **分页加载**: 每个项目下的会话分页加载，点击"显示更多"加载更多
- **项目切换器**: 顶部下拉菜单快速切换当前工作目录
- **通知历史**: 活跃标签页底部展示已完成/出错的通知记录

- **宽度调整**: 桌面端支持拖拽调整侧边栏宽度，宽度持久化到本地存储

**验收标准**:

- 当前项目对应的分组默认展开
- 活跃会话分组显示状态指示点（工作中=绿色脉冲、等待权限=黄色、等待回答=蓝色、重试=黄色）
- 编辑模式下支持 Shift+点击进行范围选择
- 移动端侧边栏滑出超过 80px 时松手自动关闭

### FR-09 活跃会话状态追踪

| 属性   | 描述         |
| ------ | ------------ |
| 标识   | FR-09        |
| 名称   | 活跃会话状态 |
| 优先级 | P1           |

**描述**: 实时追踪并展示所有活跃会话的状态：

- **状态类型**: 工作中（working）、等待权限（awaitingPermission）、等待回答（awaitingAnswer）、重试中（retrying）
- **树形结构**: 子会话挂在父会话下方，形成层级展示
- **状态聚合**: 项目分组收起时，聚合显示该目录下所有活跃会话的最高优先级状态
- **关注计数**: 侧边栏"活跃"标签显示活跃会话数 + 未读通知数的总和
- **跨目录拉取**: 活跃会话可能来自不同目录，自动补充拉取缺失的会话元数据

**验收标准**:

- 状态变化时侧边栏实时更新
- 点击活跃会话项跳转到对应会话并切换工作目录
- 会话完成后从活跃列表移除并转为通知

## 4. 关键实体

### 4.1 ChatPane（聊天窗格）

聊天界面的核心渲染单元。每个窗格包含完整的聊天表面：头部、消息区域、输入框、权限/问题对话框。

**属性**:

- `paneId`: 窗格唯一标识
- `sessionId`: 当前关联的会话 ID
- `isFocused`: 是否为当前聚焦窗格
- `displayMode`: 展示模式（`single` 单窗格 / `split` 分屏）
- `paneCount`: 当前窗格总数

**职责**:

- 管理窗格内的聊天会话生命周期
- 协调模型选择、Agent 切换、消息发送/接收
- 处理权限请求和提问请求的回复
- 注册窗格控制器到全局 Store，供快捷键和外部操作调用
- 保护当前查看的会话不被内存回收

### 4.2 InputBox（输入框）

用户输入消息的复合组件，包含文本输入、附件管理、提及/命令菜单、工具栏和底部信息栏。

**属性**:

- `text`: 当前输入文本
- `attachments`: 已附加的文件/提及/命令列表
- `mentionOpen/slashOpen`: 提及/命令菜单的开关状态
- `isSubmitting`: 是否正在提交
- `isCollapsed`: 移动端是否处于收起状态

**职责**:

- 文本输入与自动高度调整
- 文件附件管理（选择、拖拽、粘贴、删除）
- @ 提及和 / 命令的触发、导航和选择
- 输入历史导航（上下箭头）
- 移动端收起/展开交互
- 浮动操作按钮（滚动到底部、撤销重做、收起的权限/问题胶囊）

### 4.3 Sidebar（侧边栏）

会话导航和管理面板，支持桌面端停靠和移动端覆盖两种模式。

**属性**:

- `isOpen`: 侧边栏是否打开
- `selectedSessionId`: 当前选中的会话 ID
- `isResizing`: 是否正在调整宽度

**职责**:

- 展示会话列表（按项目分组或平铺）
- 活跃会话状态追踪
- 项目/目录管理（添加、移除、排序、切换）
- 会话搜索、重命名、删除、批量操作
- 通知历史展示和管理
- 上下文使用量展示
- 主题切换和设置入口

### 4.4 PermissionDialog（权限确认面板）

展示 AI 的权限请求并收集用户决策。

**属性**:

- `request`: 权限请求对象（权限类型、模式、元数据）
- `queueLength`: 队列中剩余请求数量
- `collapsed`: 是否收起

**职责**:

- 展示权限类型和请求内容
- 文件编辑类权限展示 diff 预览
- 提供"允许一次"、"始终允许"、"拒绝"三个操作
- 支持收起/展开动画
- 标识来自子 Agent 的请求

### 4.5 QuestionDialog（问题回答面板）

展示 AI 的提问并收集用户答案。

**属性**:

- `request`: 问题请求对象（包含多个问题）
- `answers`: 每个问题的已选答案
- `customEnabled/customValues`: 自定义输入的启用状态和值

**职责**:

- 展示每个问题的标题、描述和选项列表
- 支持单选/多选模式
- 支持自定义文本输入
- 校验所有问题均有答案后允许提交
- 支持收起/展开

### 4.6 SplitContainer（分屏容器）

递归渲染窗格树，管理分隔线拖拽和全屏模式。

**属性**:

- `node`: 窗格树节点（叶子节点或拆分节点）
- `fullscreenPaneId`: 全屏展示的窗格 ID

**职责**:

- 递归渲染窗格树
- 渲染可拖拽的分隔线
- 处理拖拽调整比例（rAF 节流，直接操作 DOM）
- 全屏模式下隐藏非目标窗格

### 4.7 ChatViewport（视口上下文）

响应式视口计算系统，决定 UI 的展示模式和交互行为。

**属性**:

- `surfaceVariant`: `desktop` 或 `compact`
- `interaction.mode`: `pointer` 或 `touch`
- `sidebarBehavior/rightPanelBehavior/bottomPanelBehavior`: `docked` 或 `overlay`

**职责**:

- 根据视口宽度计算展示模式（断点：768px 移动、680px 紧凑）
- 计算侧边栏、右侧面板、底部面板的宽度和行为
- 确保聊天表面最小宽度（380px）
- 判断是否允许分屏（触摸设备需 >= 900px 且横屏）

## 5. 验收场景

### 场景 1: 发送消息并接收流式响应

```
给定 用户已打开聊天界面并选中一个会话
当 用户在输入框中输入文本并发送
那么 消息出现在聊天区域（用户侧，右对齐）
并且 AI 的回复以流式方式逐字展示
并且 聊天区域自动滚动到最新消息
当 用户向上滚动查看历史
那么 自动滚动停止，不再跟随新消息
当 用户滚回底部
那么 自动滚动恢复
```

### 场景 2: 处理文件编辑权限请求

```
给定 AI 正在工作中并请求编辑某个文件的权限
那么 输入框上方弹出权限确认面板
并且 面板显示权限类型（edit/write）
并且 面板展示文件变更的 diff 预览
当 用户点击"允许一次"
那么 权限请求被批准，AI 继续执行
当 用户点击"始终允许"
那么 该权限模式被加入自动批准规则，后续同类请求自动通过
当 用户点击"拒绝"
那么 权限请求被拒绝，AI 收到拒绝反馈
```

### 场景 3: 分屏布局操作

```
给定 用户处于单窗格模式
当 用户点击分屏按钮（水平或垂直）
那么 界面拆分为两个窗格
并且 新窗格进入新会话或空状态
当 用户拖拽分隔线
那么 两个窗格的比例实时调整
当 用户松开鼠标
那么 比例被持久化
当 用户拖拽一个窗格的头部到另一个窗格上
那么 两个窗格的内容交换
当 用户点击全屏按钮
那么 当前窗格占满整个区域，其他窗格隐藏
```

### 场景 4: 侧边栏会话管理

```
给定 侧边栏处于展开状态
当 用户在搜索框中输入关键词
那么 会话列表按标题过滤
当 用户点击某个会话
那么 主区域切换到该会话
并且 移动端下侧边栏自动关闭
当 用户进入编辑模式并选择多个会话
那么 显示批量删除按钮
当 用户确认批量删除
那么 选中的会话被删除
并且 如果当前选中的会话被删除，自动创建新会话
```

### 场景 5: 活跃会话状态追踪

```
给定 有多个会话正在工作中
当 用户切换到侧边栏"活跃"标签
那么 显示所有活跃会话的树形列表
并且 每个会话显示当前状态（工作中/等待权限/等待回答/重试）
并且 子会话挂在父会话下方
当 某个会话完成工作
那么 它从活跃列表移除
并且 在通知区域显示完成通知
```

### 场景 6: 模型选择

```
给定 用户点击模型选择器
那么 弹出模型列表，按提供商分组
并且 置顶模型和最近使用模型优先展示
当 用户在搜索框中输入
那么 列表按名称/ID/提供商过滤
当 用户选择某个模型
那么 该模型被设为当前会话的默认模型
并且 选择被记录到使用历史
```

### 场景 7: 移动端响应式

```
给定 用户在移动设备上（视口 < 768px）
那么 侧边栏为覆盖式，默认隐藏
那么 输入框支持收起为胶囊
当 用户从屏幕左边缘向右滑动
那么 侧边栏跟随手指滑出
当 滑动超过 80px 后松手
那么 侧边栏完全打开
当 滑动不足 80px 后松手
那么 侧边栏弹回关闭状态
当 用户滚动消息列表
那么 输入框自动收起
当 用户点击胶囊
那么 输入框展开
```

### 场景 8: 会话分享

```
给定 用户已打开一个有消息的会话
当 用户点击分享按钮
那么 弹出分享对话框
当 用户点击"创建公开链接"
那么 调用分享 API 生成 URL
并且 URL 显示在对话框中
当 用户点击复制按钮
那么 链接被复制到剪贴板
并且 按钮显示成功反馈（2 秒后恢复）
当 用户点击"停止分享"
那么 分享链接被撤销
```

## 7. 非功能需求

### 7.1 性能

- 消息列表使用 `column-reverse` 布局实现零 JS 底部锚定
- 远离视口的消息使用虚拟渲染，仅保留测量高度
- 分屏拖拽调整比例时直接操作 DOM，绕过渲染框架，rAF 节流
- 全屏模式使用 `content-visibility: hidden` 隐藏非目标窗格，避免卸载/重装开销
- 侧边栏宽度调整使用 rAF 节流

### 7.2 响应式适配

- 断点：768px（移动/桌面）、680px（紧凑/标准）、1100px（小桌面）
- 触摸设备分屏限制：宽度 >= 900px 且横屏
- 移动端侧边栏为覆盖式，支持滑动手势
- 安全区域适配（`--safe-area-inset-*`）

### 7.3 国际化

- 所有用户可见文本通过 i18n 键值管理
- 支持 `chat` 和 `common` 两个命名空间

### 7.4 可访问性

- 所有交互按钮提供 `aria-label`
- 重试状态使用 `role="status"` 和 `aria-live="polite"`
- 键盘导航支持：菜单项上下箭头、Enter 确认、Esc 关闭

## 8. 状态管理

### 8.1 窗格布局 Store

管理窗格树结构、拆分比例、全屏状态、焦点窗格。窗格树为二叉树结构，叶子节点为具体窗格，内部节点为拆分节点（含方向和比例）。

### 8.2 消息 Store

管理会话消息、流式状态、权限/提问请求队列。保护当前查看的会话不被内存回收。

### 8.3 自动批准 Store

管理全局和会话级的自动批准规则，支持三态切换（关闭/会话级/全局级）。

### 8.4 通知 Store

管理通知历史记录，支持标记已读、全部清除、 dismissed 状态。

### 8.5 布局 Store

管理侧边栏、右侧面板、底部面板的开关状态和宽度。

### 8.6 目录 Store

管理已添加的项目/目录列表、当前工作目录、最近使用记录、目录排序。

## 9. 数据流概览

```
用户输入 → InputBox → handleSend → useChatSession → 后端 API
                                                    ↓
后端 SSE 流 ← useChatSession ← ChatArea ← 消息 Store
                    ↓
            权限/提问请求 → PermissionDialog / QuestionDialog
                    ↓
            用户回复 → handlePermissionReply / handleQuestionReply → 后端 API
```

侧边栏数据流：

```
Session Context → SidePanel → SessionList / FolderRecentList / ActiveSessionItem
       ↓
   用户选择会话 → onSelectSession → 导航到会话 → ChatPane 加载消息
```
