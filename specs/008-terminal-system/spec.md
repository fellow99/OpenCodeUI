## 1. 模块概述

### 1.1 目的

终端系统为应用提供完整的 Web 终端能力，使用户可以在浏览器内获得与本地终端一致的交互体验。通过伪终端（PTY）后端与 WebSocket 双向通信，实现命令执行、输出渲染、动态调整大小等核心功能。

### 1.2 解决的问题

- **完整 Shell 访问**：在 Web 界面内直接运行任意 Shell 命令，无需切换到外部终端
- **实时双向通信**：用户输入与终端输出通过 WebSocket 低延迟传输
- **ANSI 色彩还原**：完整支持终端转义序列，正确渲染彩色输出
- **多会话管理**：同时运行多个终端实例，通过标签页切换
- **移动端适配**：触屏设备提供辅助按键栏，解决虚拟键盘缺少功能键的问题
- **会话持久化**：页面刷新后自动恢复已有终端会话

### 1.3 范围

本模块涵盖：

- PTY 会话的创建、查询、更新、销毁
- WebSocket 双向 I/O 连接管理（含自动重连）
- 终端渲染引擎初始化与生命周期管理
- 动态大小调整（窗口 resize、面板拖拽、标签切换）
- 多终端标签页管理（创建、关闭、切换、拖拽排序）
- 主题适配（明暗模式自动切换）
- 移动端辅助按键（粘滞修饰键、方向键、功能键）
- 触屏滚动优化（惯性滚动、滚动条淡入淡出）
- 终端会话跨页面恢复

本模块不涵盖：

- PTY 后端的进程管理（由 OpenCode 后端负责）
- Shell 命令的语法解析与执行（由系统 Shell 负责）

## 3. 功能需求

### FR-01：PTY 会话管理

**描述**：通过 REST API 管理伪终端会话的完整生命周期。

**要求**：

- 支持创建 PTY 会话，指定工作目录（cwd）
- 支持查询已有 PTY 会话列表，用于页面恢复
- 支持获取单个 PTY 会话的详细信息
- 支持更新 PTY 会话属性（如终端行列数）
- 支持删除 PTY 会话，释放后端资源
- 所有 API 调用携带目录参数，实现多项目隔离

**验收标准**：

- 给定工作目录，创建 PTY 会话返回唯一的会话 ID
- 给定会话 ID，可以查询到会话的当前状态（running / exited）
- 删除已退出的会话不抛出异常

### FR-02：WebSocket 双向通信

**描述**：终端与后端 PTY 之间通过 WebSocket 建立实时双向 I/O 通道。

**要求**：

- WebSocket URL 基于当前活动服务器的 HTTP URL 自动转换（http 转 ws，https 转 wss）
- 认证信息通过 URL userinfo 传递（WebSocket 不支持自定义请求头）
- 用户键盘输入实时发送至 WebSocket
- 后端输出通过 WebSocket 接收并渲染到终端
- 连接断开后自动重连，采用指数退避策略（起始 1 秒，最大 30 秒）
- 重连期间在终端内显示倒计时提示
- 主动关闭或正常关闭（code 1000）不触发重连

**验收标准**：

- 给定已配置密码的服务器，WebSocket URL 包含 userinfo 部分
- 给定网络断开，终端显示重连提示并在 30 秒内自动恢复
- 给定用户主动关闭终端，不触发重连

### FR-03：终端渲染与 ANSI 支持

**描述**：终端组件提供完整的终端仿真能力，正确解析和渲染 ANSI 转义序列。

**要求**：

- 支持完整的 ANSI 色彩序列（16 色及 256 色）
- 支持光标控制、清屏、滚动等终端控制序列
- 支持文本选择与复制
- 支持超链接检测与点击打开
- 滚动缓冲区至少支持 10000 行
- 行结束符自动转换（convertEol）
- 光标闪烁效果

**验收标准**：

- 给定包含 ANSI 色彩码的输出，终端正确渲染对应颜色
- 给定长输出，用户可以通过滚动查看历史内容
- 给定输出中的 URL，用户可以点击在新窗口打开

### FR-04：动态大小调整

**描述**：终端行列数随容器尺寸变化自动调整，并同步至后端 PTY。

**要求**：

- 监听窗口 resize 事件和容器 ResizeObserver
- 面板拖拽调整期间暂停 resize，结束后立即适配
- 使用防抖机制（16ms）避免频繁调整
- 调整后通过 API 将新的 cols/rows 同步至后端
- 标签切换时自动触发 fit 操作

**验收标准**：

- 给定浏览器窗口大小变化，终端在 16ms 内完成适配
- 给定面板拖拽调整，拖拽期间不触发 resize，结束后立即适配
- 给定标签切换，新激活的终端自动适配容器尺寸

### FR-05：硬件加速渲染

**描述**：终端使用 WebGL 进行渲染，提升大输出量场景下的性能表现。

**要求**：

- 优先使用 WebGL 渲染器
- WebGL 不可用时自动降级至 Canvas 渲染
- 渲染器与终端核心逻辑解耦

**验收标准**：

- 给定支持 WebGL 的浏览器，终端使用 WebGL 渲染
- 给定不支持 WebGL 的环境，终端自动降级至 Canvas 渲染
- 大量输出场景下帧率保持稳定

### FR-06：Unicode 字符支持

**描述**：终端完整支持 Unicode 字符的渲染，包括多字节字符和宽字符。

**要求**：

- 支持 CJK 字符（中文、日文、韩文）正确占位
- 支持 Emoji 表情渲染
- 支持组合字符（combining characters）
- 字体使用系统等宽字体栈，优先使用 CSS 变量定义的等宽字体

**验收标准**：

- 给定包含中文的输出，字符对齐正确，无重叠或截断
- 给定包含 Emoji 的输出，表情符号正常显示
- 给定不同语言的 Unicode 文本，渲染结果正确

### FR-07：终端生命周期管理

**描述**：终端组件从创建到销毁的完整生命周期管理。

**要求**：

- **创建阶段**：初始化终端实例、加载扩展插件、打开 DOM 容器、建立 WebSocket 连接
- **运行阶段**：处理用户输入、渲染后端输出、响应大小变化、响应主题变化
- **暂停阶段**：非活动标签的终端隐藏但保持连接
- **销毁阶段**：关闭 WebSocket 连接、清理重连计时器、销毁终端实例、释放内存
- 使用 mountedRef 防止组件卸载后的状态更新
- 清理函数确保所有资源正确释放（addons、事件监听器、WebSocket、计时器）

**验收标准**：

- 给定终端组件挂载，WebSocket 连接建立且终端可交互
- 给定终端组件卸载，所有资源正确释放，无内存泄漏
- 给定组件快速挂载卸载，不会残留异步操作

### FR-08：多终端会话管理

**描述**：支持同时运行多个终端实例，通过标签页进行切换和管理。

**要求**：

- 每个终端实例对应一个独立的 PTY 会话
- 标签页显示终端标题、连接状态指示器
- 支持拖拽排序标签页
- 支持关闭标签页（同时销毁对应 PTY 会话）
- 活动标签的关闭按钮始终可见，非活动标签的关闭按钮悬停显示
- 状态指示器颜色：connecting（黄色）、connected（绿色）、disconnected（灰色）、exited（红色）
- 终端标签按工作目录分组持久化

**验收标准**：

- 给定多个终端标签，只有活动标签可见且可交互
- 给定拖拽标签 A 到标签 B 位置，标签顺序正确交换
- 给定关闭标签，对应 PTY 会话被销毁，标签从列表中移除
- 给定所有标签关闭，底部面板自动隐藏

### FR-09：主题适配

**描述**：终端主题随应用明暗模式自动切换。

**要求**：

- 从 CSS 变量动态读取前景色（HSL 格式转换为 hex）
- 背景色透明，由容器 CSS 控制
- 监听 `data-mode` 属性变化，自动更新终端主题
- 明暗模式各有完整的 16 色调色板（标准色 + 高亮色）
- 光标、选区颜色随主题适配

**验收标准**：

- 给定应用切换到暗色模式，终端前景色和 ANSI 颜色切换为暗色配色
- 给定应用切换到亮色模式，终端前景色和 ANSI 颜色切换为亮色配色
- 主题切换过程中终端内容不闪烁

### FR-10：移动端辅助按键

**描述**：触屏设备在终端底部提供辅助按键栏，弥补虚拟键盘功能键缺失。

**要求**：

- 两行辅助按键：
  - 第一行：ESC、/、-、HOME、↑、END、PGUP
  - 第二行：TAB、CTRL（粘滞）、ALT（粘滞）、←、↓、→、PGDN
- CTRL 和 ALT 为粘滞修饰键，点击激活后下一次按键自动附带修饰
- 粘滞修饰键支持同时激活
- 修饰键在输入后或失焦时自动清除
- 按键发送后自动聚焦回终端输入区

**验收标准**：

- 给定触屏设备，终端底部显示辅助按键栏
- 给定点击 CTRL 键后输入 a，实际发送 Ctrl+A
- 给定同时激活 CTRL 和 ALT，下一次输入同时附带两种修饰
- 给定输入完成后，粘滞修饰键自动清除

### FR-11：触屏滚动优化

**描述**：触屏设备提供流畅的终端滚动体验。

**要求**：

- 自定义 touch 事件处理，阻止默认行为避免页面滚动
- 惯性滚动：松手后按 0.95 摩擦系数减速，速度低于 0.5 px/帧时停止
- 滚动条淡入淡出：滚动时显示，空闲 600ms 后淡出
- 滚动阈值 6px，避免误触

**验收标准**：

- 给定触屏设备滑动终端内容，页面不跟随滚动
- 给定快速滑动后松手，终端继续惯性滚动
- 给定停止滚动 600ms 后，滚动条淡出

### FR-12：终端会话恢复

**描述**：页面加载或切换工作目录时，自动恢复已有的 PTY 会话。

**要求**：

- 页面加载时查询后端已有 PTY 会话列表
- 为每个已有会话创建对应的标签页（不自动打开面板）
- 切换工作目录时重新拉取该目录下的 PTY 会话并同步
- 使用 requestId 机制避免并发恢复导致的状态混乱
- 恢复期间显示加载状态

**验收标准**：

- 给定页面刷新，已有终端会话自动恢复为标签页
- 给定切换工作目录，新目录下的终端会话正确加载
- 给定快速切换目录，仅最后一次请求生效

## 4. 关键实体

### 4.1 PTY 会话

| 属性   | 类型   | 说明                          |
| ------ | ------ | ----------------------------- |
| id     | string | 会话唯一标识                  |
| title  | string | 终端标题（由 Shell 动态设置） |
| status | string | 会话状态：running / exited    |
| size   | object | 终端行列数 { cols, rows }     |
| cwd    | string | 工作目录                      |

**行为**：

- 通过 REST API 创建、查询、更新、销毁
- 通过 WebSocket 进行实时 I/O 通信
- 状态变更通过 SSE 事件通知前端

### 4.2 终端实例

| 属性      | 类型    | 说明                                                     |
| --------- | ------- | -------------------------------------------------------- |
| ptyId     | string  | 关联的 PTY 会话 ID                                       |
| directory | string? | 工作目录                                                 |
| isActive  | boolean | 是否为当前活动终端                                       |
| status    | string  | 连接状态：connecting / connected / disconnected / exited |
| title     | string  | 显示标题                                                 |

**行为**：

- 初始化终端渲染引擎并挂载到 DOM
- 建立并维护 WebSocket 连接
- 处理用户输入并发送至后端
- 接收后端输出并渲染
- 响应容器尺寸变化
- 响应主题变化

### 4.3 终端标签页

| 属性   | 类型   | 说明                        |
| ------ | ------ | --------------------------- |
| id     | string | 标签唯一标识（等于 PTY ID） |
| title  | string | 显示标题                    |
| status | string | 连接状态指示                |

**行为**：

- 点击切换活动终端
- 拖拽调整排序
- 关闭按钮销毁对应 PTY 会话
- 状态指示器实时反映连接状态

### 4.4 WebSocket 连接

| 属性             | 类型    | 说明                         |
| ---------------- | ------- | ---------------------------- |
| url              | string  | WebSocket 连接地址           |
| readyState       | number  | 连接状态（OPEN / CLOSED 等） |
| reconnectCount   | number  | 当前重连次数                 |
| intentionalClose | boolean | 是否为主动关闭               |

**行为**：

- 连接建立后发送当前终端尺寸
- 接收后端数据并写入终端
- 连接断开后按指数退避自动重连
- 主动关闭不触发重连

## 5. 数据流

### 5.1 用户输入流

```
用户键盘输入
    ↓
终端组件捕获 onData 事件
    ↓
应用粘滞修饰键（CTRL / ALT）
    ↓
通过 WebSocket.send() 发送至后端
    ↓
PTY 后端接收并传递给 Shell 进程
```

### 5.2 终端输出流

```
Shell 进程产生输出
    ↓
PTY 后端捕获输出
    ↓
通过 WebSocket.onmessage 推送至前端
    ↓
终端组件调用 terminal.write() 渲染
    ↓
ANSI 转义序列解析 → 像素渲染到画布/DOM
```

### 5.3 大小调整流

```
窗口 resize / 面板拖拽 / 标签切换
    ↓
ResizeObserver / 事件监听器触发
    ↓
防抖 16ms
    ↓
fitAddon.fit() 重新计算行列数
    ↓
updatePtySession() API 同步至后端
    ↓
PTY 后端调整进程窗口大小
```

### 5.4 会话恢复流

```
页面加载 / 目录切换
    ↓
listPtySessions() 查询已有会话
    ↓
与现有标签页对比，去重
    ↓
为每个新会话创建标签页
    ↓
终端组件挂载时自动连接 WebSocket
```

## 7. 验收场景

### 场景 1：创建并执行终端命令

**前置条件**：应用已连接后端，底部面板已打开

**步骤**：

1. 点击新建终端按钮
2. 等待终端连接成功
3. 输入 `echo hello` 并按回车

**预期结果**：

- 新标签页出现在底部面板，状态指示器从黄色变为绿色
- 终端显示 Shell 提示符
- 输入 `echo hello` 后，终端输出 `hello`
- 新的 Shell 提示符出现在输出下方

### 场景 2：终端 ANSI 色彩渲染

**前置条件**：终端已连接

**步骤**：

1. 输入 `ls --color=auto` 并执行

**预期结果**：

- 目录、文件、可执行文件等以不同颜色显示
- 颜色与本地终端一致
- 无乱码或未解析的转义序列

### 场景 3：动态大小调整

**前置条件**：终端已连接并显示内容

**步骤**：

1. 拖拽底部面板上边缘调整高度
2. 调整浏览器窗口宽度

**预期结果**：

- 拖拽期间终端不闪烁
- 拖拽结束后终端立即适配新高度
- 窗口宽度变化后终端列数自动调整
- 后端 PTY 收到新的行列数

### 场景 4：多终端并行操作

**前置条件**：已有一个活动终端

**步骤**：

1. 点击新建终端按钮创建第二个终端
2. 在第一个终端运行 `sleep 10`
3. 切换到第二个终端运行 `pwd`
4. 切换回第一个终端

**预期结果**：

- 两个终端独立运行，互不干扰
- 第一个终端的 `sleep` 命令在后台继续执行
- 切换回第一个终端时，可以看到 `sleep` 命令的输出或仍在运行

### 场景 5：网络断开与自动重连

**前置条件**：终端已连接

**步骤**：

1. 模拟网络断开（停止后端服务）
2. 等待 1 秒
3. 恢复网络（重启后端服务）

**预期结果**：

- 终端显示 `[Disconnected, reconnecting in 1s...]`
- 1 秒后自动发起重连
- 后端恢复后连接状态变为 connected
- 终端可继续正常交互
- 如果多次重连失败，延迟按指数增长，最大 30 秒

### 场景 6：页面刷新后会话恢复

**前置条件**：已创建两个终端会话

**步骤**：

1. 刷新浏览器页面
2. 等待页面加载完成

**预期结果**：

- 底部面板不自动打开（恢复时不弹出）
- 两个终端标签页出现在标签栏中
- 标签顺序与刷新前一致
- 点击标签可正常连接并交互

### 场景 7：移动端辅助按键

**前置条件**：触屏设备访问，终端已连接

**步骤**：

1. 点击 CTRL 键（高亮显示）
2. 点击 C 键（或输入 c）
3. 观察粘滞修饰键状态

**预期结果**：

- CTRL 键激活后高亮显示
- 下一次输入自动附带 Ctrl 修饰（发送 Ctrl+C）
- 输入完成后 CTRL 键自动取消高亮
- 终端收到中断信号

### 场景 8：主题切换

**前置条件**：终端已连接并显示内容

**步骤**：

1. 将应用主题从亮色切换为暗色
2. 观察终端颜色变化

**预期结果**：

- 终端前景色、ANSI 颜色、光标颜色平滑过渡
- 背景保持透明，由容器 CSS 控制
- 终端内容不闪烁、不丢失

### 场景 9：标签拖拽排序

**前置条件**：存在至少两个终端标签

**步骤**：

1. 拖拽标签 A 到标签 B 的位置

**预期结果**：

- 标签 B 显示高亮边框表示放置目标
- 释放后标签 A 移动到标签 B 的位置
- 排序状态持久化到 localStorage

### 场景 10：关闭终端

**前置条件**：存在一个活动终端

**步骤**：

1. 点击终端标签的关闭按钮

**预期结果**：

- 对应 PTY 会话被销毁
- 标签从标签栏移除
- 如果这是最后一个标签，底部面板自动关闭
- 如果有其他标签，自动切换到相邻标签

## 9. 架构决策记录

### ADR-001：为什么 WebSocket 认证通过 URL userinfo

**决策**：WebSocket 连接将认证信息编码到 URL 的 userinfo 部分（`ws://user:pass@host/path`）。

**理由**：

- WebSocket 协议不支持自定义请求头
- URL userinfo 是 RFC 标准中定义的认证传递方式
- 后端已支持从 URL 解析认证信息
- SDK 不处理 WebSocket 连接，URL 构建由前端手动完成

### ADR-002：为什么非活动终端保持连接而非销毁

**决策**：切换到其他标签时，非活动终端实例保持挂载但隐藏（visibility: hidden），不销毁。

**理由**：

- 销毁重建会导致终端内容丢失
- 保持连接确保后台命令继续运行
- 隐藏而非销毁使切换回活动标签时即时响应
- 使用 pointerEvents: none 防止非活动终端接收输入

### ADR-003：为什么面板拖拽期间暂停终端 resize

**决策**：面板拖拽调整期间（panel-resize-start 到 panel-resize-end），终端不执行 resize 操作。

**理由**：

- 拖拽过程中容器尺寸频繁变化，频繁 fit 会导致性能问题
- 拖拽结束后一次性 fit 即可得到正确尺寸
- 避免拖拽过程中终端内容闪烁

### ADR-004：为什么移动端使用粘滞修饰键而非长按

**决策**：CTRL 和 ALT 键采用粘滞（sticky）模式，点击激活后下一次输入自动附带修饰。

**理由**：

- 参考 Termux、Blink Shell 等成熟终端应用的方案
- 长按交互在触屏上不够精确
- 粘滞模式允许用户先按修饰键再按目标键，符合物理键盘习惯
- 支持多个修饰键同时激活

### ADR-005：为什么终端标签按目录分组持久化

**决策**：终端标签的排序和活动状态按工作目录分别存储到 localStorage。

**理由**：

- 不同项目可能有不同的终端布局偏好
- 切换目录时恢复该目录下的终端布局
- 避免不同项目的终端标签互相干扰

## 10. 风险与缓解

| 风险                         | 影响                               | 缓解措施                                              |
| ---------------------------- | ---------------------------------- | ----------------------------------------------------- |
| WebSocket 连接泄漏           | 组件卸载后连接未关闭，占用后端资源 | 清理函数中显式关闭 WebSocket，使用 mountedRef 防护    |
| 频繁 resize 导致性能下降     | 窗口快速变化时终端频繁重绘         | 16ms 防抖 + 面板拖拽期间暂停 resize                   |
| 移动端虚拟键盘遮挡终端输入区 | 用户无法看到输入内容               | 终端 textarea 设置 inputmode、enterkeyhint 等属性优化 |
| 大量终端标签导致内存占用过高 | 同时打开过多终端实例消耗资源       | 每个终端独立生命周期管理，关闭时彻底释放资源          |
| 主题切换时 CSS 变量未就绪    | 终端颜色短暂异常                   | getHSLColor 函数在变量为空时返回默认颜色兜底          |
| 并发目录切换导致状态混乱     | 快速切换目录时终端标签状态不一致   | requestId 机制确保仅最后一次请求生效                  |
