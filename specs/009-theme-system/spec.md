# 主题系统规范 (Theme System Specification)

## 1. 模块概述

主题与外观系统（Theme & Appearance System）负责 OpenCodeUI 的视觉定制能力。用户可通过内置主题预设快速切换整体配色风格，也可通过自定义 CSS 覆盖任意视觉细节。系统支持明暗模式切换、系统偏好自动检测、跨会话持久化，以及无刷新的运行时主题切换。

**设计目标：**

- 提供开箱即用的多套主题预设，满足不同审美偏好
- 允许高级用户通过 CSS 变量体系深度定制界面外观
- 主题切换即时生效，无需页面重载
- 用户偏好自动保存，下次打开时恢复

## 3. 功能需求

### FR-01：主题预设

系统内置三套主题预设，每套预设包含独立的亮色和暗色两套配色方案：

| 预设 ID      | 名称       | 设计理念                                                 |
| ------------ | ---------- | -------------------------------------------------------- |
| `eucalyptus` | Eucalyptus | 莫兰迪色系，桉树绿品牌色，高级灰调，清爽冷静（默认主题） |
| `claude`     | Claude     | 暖调橙色品牌色，经典风格                                 |
| `breeze`     | Breeze     | 冷色调蓝绿品牌色，清新护眼，低饱和度                     |

此外提供 `custom` 预设选项，允许用户通过自定义 CSS 完全接管主题配色。

### FR-02：颜色模式

支持三种颜色模式：

- **system**：跟随操作系统偏好，自动检测并响应系统级明暗模式变化
- **light**：强制使用亮色模式
- **dark**：强制使用暗色模式

用户在设置面板中通过分段控制器（Segmented Control）进行切换，切换时可选配圆形扩散动画效果。

### FR-03：自定义 CSS

用户可在设置面板的文本编辑器中输入自定义 CSS 代码，系统实时应用这些样式。提供一键加载模板功能，模板包含完整的 CSS 变量覆盖示例（亮色/暗色/系统自动三套）。自定义 CSS 通过独立的 `<style>` 元素注入页面头部，优先级高于主题预设变量。

### FR-04：CSS 变量体系

所有主题颜色值通过 CSS 自定义属性（CSS Variables）暴露，供组件样式引用。变量命名遵循语义化规范：

**背景色：** `--bg-000` 至 `--bg-400`（从最亮到最深）

**文本色：** `--text-000` 至 `--text-600`（从纯白到最浅占位符色）

**品牌色：** `--accent-brand`、`--accent-main-000/100/200`、`--accent-secondary-100`

**语义色：** `--success-*`、`--warning-*`、`--danger-*`、`--info-*`（含前景色与背景色）

**边框色：** `--border-100/200/300`

**特殊色：** `--always-black`、`--always-white`、`--oncolor-100`

颜色值采用 HSL 格式（不含 `hsl()` 包装），如 `165 45% 42%`，由样式层统一包裹。

### FR-05：主题持久化

用户选择的主题预设 ID、颜色模式和自定义 CSS 分别持久化至本地存储。页面重新加载时自动读取并恢复上次保存的偏好设置。

### FR-06：系统偏好检测

当颜色模式设为 `system` 时，系统通过浏览器 API 检测操作系统的明暗模式偏好。当系统偏好发生变化时（如从白天切换到夜间），界面自动响应并更新配色，无需用户手动操作。

### FR-07：运行时主题切换

主题切换在运行时即时生效，无需页面重载。切换流程包括：更新 DOM 上的 `data-mode` 属性、注入新的 CSS 变量值、应用自定义 CSS、更新移动端状态栏颜色。支持通过 View Transition API 实现圆形扩散动画效果。

## 4. 关键实体

### Theme（主题预设）

一套完整的视觉配色方案，包含亮色和暗色两套颜色定义。

| 属性          | 类型        | 说明                        |
| ------------- | ----------- | --------------------------- |
| `id`          | string      | 唯一标识符，如 `eucalyptus` |
| `name`        | string      | 显示名称，如 `Eucalyptus`   |
| `description` | string      | 简短描述                    |
| `light`       | ThemeColors | 亮色模式下的颜色定义        |
| `dark`        | ThemeColors | 暗色模式下的颜色定义        |

### ColorMode（颜色模式）

枚举类型，取值范围为 `system` | `light` | `dark`。

### ThemeState（主题状态）

聚合了所有外观相关设置的完整状态对象，包含：

| 属性                      | 类型                 | 说明                         |
| ------------------------- | -------------------- | ---------------------------- |
| `presetId`                | string               | 当前主题预设 ID              |
| `colorMode`               | ColorMode            | 当前颜色模式                 |
| `customCSS`               | string               | 用户自定义 CSS 代码          |
| `collapseUserMessages`    | boolean              | 是否自动折叠长用户消息       |
| `stepFinishDisplay`       | StepFinishDisplay    | 步骤完成信息栏显示开关       |
| `reasoningDisplayMode`    | ReasoningDisplayMode | 思考内容展示模式             |
| `wideMode`                | boolean              | 宽模式开关                   |
| `diffStyle`               | DiffStyle            | Diff 行标记风格              |
| `descriptiveToolSteps`    | boolean              | 是否启用带工具描述的步骤摘要 |
| `inlineToolRequests`      | boolean              | 是否内嵌工具权限/提问请求    |
| `codeWordWrap`            | boolean              | 代码块自动换行               |
| `toolCardStyle`           | ToolCardStyle        | 工具输出渲染风格             |
| `immersiveMode`           | boolean              | 沉浸模式                     |
| `compactInlinePermission` | boolean              | 内嵌权限精简模式             |
| `glassEffect`             | boolean              | 毛玻璃效果开关               |
| `queueFollowupMessages`   | boolean              | 忙碌时后续消息入队           |

### ThemeColors（颜色定义）

单个模式（亮色或暗色）下的完整颜色集合，按用途分为背景、文本、品牌、语义、边框、特殊六个类别。

## 5. 主题架构

```
主题预设 (ThemePreset)
    │
    ├── 亮色配色 (ThemeColors.light)
    │       │
    │       └── 背景 / 文本 / 品牌 / 语义 / 边框 / 特殊
    │
    └── 暗色配色 (ThemeColors.dark)
            │
            └── 背景 / 文本 / 品牌 / 语义 / 边框 / 特殊

                    ↓ 解析与注入

CSS 变量 (CSS Custom Properties)
    │
    ├── :root 默认回退值（index.css 中定义）
    │
    └── 动态注入的 <style> 元素（:root:root 选择器，高优先级覆盖）
            │
            └── --bg-*, --text-*, --accent-*, --success-*, --warning-*,
                --danger-*, --info-*, --border-*, --always-*, --oncolor-*

                    ↓ 组件消费

组件样式 (Component Styles)
    │
    ├── 通过 CSS 变量引用颜色值
    │
    ├── 毛玻璃效果（data-glass 属性驱动）
    │
    └── 自定义 CSS 覆盖（用户输入，最高优先级）
```

**数据流说明：**

1. 用户选择主题预设和颜色模式
2. 系统根据选择解析出对应的 ThemeColors 对象
3. 通过 `themeColorsToCSSVars` 将颜色值转换为 CSS 变量赋值语句
4. 以 `:root:root` 选择器注入 `<style>` 元素到页面头部，覆盖默认值
5. 组件通过 CSS 变量引用颜色，自动响应变化
6. 用户自定义 CSS 通过独立的 `<style>` 元素注入，优先级最高

## 6. 验收场景

### AC-01：切换内置主题

**前置条件：** 用户已打开应用，当前使用 Eucalyptus 主题

**操作步骤：**

1. 打开设置面板，进入外观选项卡
2. 点击 Claude 主题卡片

**预期结果：**

- 界面配色立即切换为 Claude 主题的橙色风格
- Claude 主题卡片显示选中状态（勾选标记）
- 页面不刷新，无闪烁
- 刷新页面后仍保持 Claude 主题

### AC-02：切换颜色模式

**前置条件：** 当前颜色模式为 system

**操作步骤：**

1. 在外观设置中点击"暗色"选项

**预期结果：**

- 界面切换为暗色模式
- 分段控制器中"暗色"选项高亮
- 移动端状态栏颜色同步更新为暗色
- 刷新页面后仍保持暗色模式

### AC-03：系统偏好自动响应

**前置条件：** 颜色模式设为 system，操作系统当前为亮色模式

**操作步骤：**

1. 将操作系统的显示模式从亮色切换为暗色

**预期结果：**

- 界面自动切换为暗色配色
- 无需用户手动操作
- 切换过程平滑，无白屏闪烁

### AC-04：自定义 CSS 覆盖

**前置条件：** 用户已打开设置面板

**操作步骤：**

1. 在自定义 CSS 编辑器中输入 `:root:root { --font-ui-sans: 'Inter', sans-serif; }`
2. 等待约 400 毫秒

**预期结果：**

- 界面字体立即更新为 Inter
- CSS 编辑器内容自动保存
- 刷新页面后自定义样式仍然生效
- 点击"清除"按钮后，自定义 CSS 被移除，界面恢复默认字体

### AC-05：自定义 CSS 模板加载

**前置条件：** 自定义 CSS 编辑器为空

**操作步骤：**

1. 点击"加载模板"按钮

**预期结果：**

- 编辑器中填入完整的主题模板代码
- 模板包含亮色、暗色、系统自动三套配色方案
- 模板包含字体覆盖示例
- 模板代码立即生效

### AC-06：主题持久化

**前置条件：** 用户已切换至 Breeze 主题和暗色模式

**操作步骤：**

1. 关闭浏览器标签页
2. 重新打开应用

**预期结果：**

- 界面自动恢复为 Breeze 主题
- 颜色模式为暗色
- 无需用户重新选择

### AC-07：毛玻璃效果切换

**前置条件：** 毛玻璃效果已开启

**操作步骤：**

1. 在外观设置中关闭毛玻璃效果开关

**预期结果：**

- 所有使用 `.glass` 和 `.glass-alt` 类的元素变为实色背景
- blur 效果被移除
- 刷新页面后设置保持关闭状态

## 7. 非功能需求

| 编号   | 需求       | 说明                                                                          |
| ------ | ---------- | ----------------------------------------------------------------------------- |
| NFR-01 | 性能       | 主题切换应在 100ms 内完成视觉更新                                             |
| NFR-02 | 兼容性     | 在 View Transition API 不可用的浏览器中，降级为即时切换                       |
| NFR-03 | 无障碍     | 尊重 `prefers-reduced-motion` 设置，禁用动画效果                              |
| NFR-04 | 移动端适配 | 主题切换时同步更新移动端状态栏颜色（通过 Android Bridge 和 meta theme-color） |
| NFR-05 | 容错性     | 自定义 CSS 解析错误时不影响主题系统正常运行                                   |
