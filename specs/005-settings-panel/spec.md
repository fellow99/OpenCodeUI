## 1. 模块概述

### 1.1 目的

设置面板是用户配置应用程序行为与外观的统一入口。通过分栏式对话框，将外观、聊天行为、通知、服务器连接、服务管理和快捷键六大类配置集中呈现，使用户能够在一个界面内完成所有个性化设置。

### 1.2 解决的问题

- **配置分散**：将原本可能散落在各处的设置项集中到单一对话框
- **多服务器管理**：支持添加、编辑、删除和切换多个后端服务器连接
- **跨平台适配**：桌面端采用左右分栏布局，移动端采用顶部标签栏横向滚动
- **快捷键冲突检测**：自定义快捷键时自动检测重复绑定
- **环境差异**：部分设置项仅在桌面应用环境下可见（如本地服务管理）

### 1.3 范围

本模块涵盖：

- 设置对话框的打开、关闭与标签页导航
- 外观设置：主题预设、明暗模式、自定义 CSS、显示选项、侧边栏行为
- 聊天设置：路径格式、自动批准、沉浸模式、思考过程显示、工具卡片样式、步骤完成信息
- 通知设置：系统通知、应用内提醒、声音总控、事件音效配置、自定义音频上传
- 服务器管理：多服务器增删改查、健康检查、认证配置、连接切换
- 服务管理：本地服务启停、二进制路径配置、环境变量管理（仅桌面端）
- 快捷键自定义：分类浏览、搜索过滤、按键捕获、冲突检测、重置默认

本模块不涵盖：

- 设置数据的持久化存储机制（由状态管理层负责）
- 国际化翻译文本的具体内容
- 主题预设的 CSS 变量定义

## 3. 功能需求

### FR-01：设置对话框与标签页导航

**描述**：设置面板以模态对话框形式呈现，左侧为导航栏，右侧为内容区。支持通过键盘方向键在标签页间切换。

**要求**：

- 对话框打开时自动定位到指定标签页，未指定时默认为服务器标签页
- 桌面端采用左右分栏布局，左侧导航栏包含分组标题和标签项
- 移动端采用顶部固定标题栏加横向滚动标签栏，内容区占满剩余空间
- 标签页分为两组：核心组（服务器、聊天、外观、通知）和高级组（服务、快捷键）
- 服务标签页仅在桌面应用环境下显示
- 切换标签页时自动滚动至内容区顶部
- 当前选中标签页在导航栏中高亮显示，非当前标签页可通过键盘聚焦
- 对话框底部显示应用版本号

**验收标准**：

- 给定打开设置对话框，默认显示服务器标签页
- 给定按下方向键，焦点在可见标签页间循环移动
- 给定在移动端打开，标签栏支持横向滚动且不溢出屏幕
- 给定在浏览器环境打开，服务标签页不可见

### FR-02：外观设置

**描述**：用户可配置应用的主题预设、颜色模式、自定义 CSS 以及各类显示选项。

**要求**：

- 提供主题预设卡片网格，每个预设包含缩略预览图和描述文字
- 颜色模式支持三种选项：跟随系统、浅色模式、深色模式，以分段控制器呈现
- 自定义 CSS 编辑器支持语法高亮风格的等宽字体文本域，带防抖保存
- 提供 CSS 模板加载按钮，在编辑器为空时显示
- 显示选项包括：宽屏模式、毛玻璃效果、代码自动换行、Diff 样式（标记模式或变更条模式）
- 侧边栏选项包括：最近文件夹样式、显示 Diff 信息、显示子会话
- 语言切换下拉菜单，支持中文和英文

**验收标准**：

- 给定点击主题预设卡片，应用对应主题并显示选中状态
- 给定切换颜色模式，界面立即响应明暗变化
- 给定在 CSS 编辑器中输入内容，400 毫秒后自动应用
- 给定点击加载模板按钮，编辑器填充预设 CSS 代码
- 给定切换宽屏模式，布局宽度发生变化

### FR-03：服务器管理

**描述**：用户可添加、编辑、删除和切换多个后端服务器连接，并查看每个服务器的健康状态。

**要求**：

- 服务器列表以卡片形式展示，每张卡片显示名称、URL、认证标识和健康状态图标
- 当前活动服务器以特殊边框和标签标识，并始终排在列表首位
- 支持添加新服务器，表单包含名称、URL 和可选的认证信息（用户名、密码）
- 支持内联编辑已有服务器，编辑表单与添加表单结构一致
- 健康检查显示五种状态：检查中、在线（含延迟和版本号）、未授权、离线、错误
- 删除非默认服务器前弹出确认对话框
- 默认服务器不可删除
- 跨域连接且配置密码时显示安全警告
- 切换服务器时清理当前会话状态并导航回首页
- 支持一键刷新所有服务器健康状态

**验收标准**：

- 给定添加有效 URL 的服务器，服务器出现在列表中并自动执行健康检查
- 给定添加无效 URL，表单显示错误提示
- 给定点击健康状态图标，显示详细状态信息（延迟、版本、错误描述）
- 给定切换服务器，当前会话被清理，页面导航回首页
- 给定尝试删除默认服务器，操作被拒绝
- 给定跨域服务器配置密码，显示安全警告提示

### FR-04：快捷键自定义

**描述**：用户可查看和修改所有键盘快捷键，按分类浏览，支持搜索和冲突检测。

**要求**：

- 快捷键按分类分组展示：通用、会话、面板、终端、模型、消息、权限
- 每个快捷键显示动作名称和当前键位组合，以按键胶囊形式呈现
- 点击快捷键进入编辑模式，捕获下一次按键组合作为新快捷键
- 编辑模式下显示实时按键反馈，冲突时显示错误提示
- 支持 Escape 取消编辑，Enter 确认编辑
- 修改过的快捷键以特殊颜色标识，并提供一键重置按钮
- 支持搜索过滤，搜索范围覆盖动作名称、描述和当前键位
- 提供重置所有快捷键为默认值的操作按钮
- 快捷键数据持久化到本地存储，仅保存与默认值不同的配置

**验收标准**：

- 给定点击快捷键，进入编辑模式并等待按键输入
- 给定输入已被其他动作使用的快捷键，显示冲突错误提示
- 给定按下 Escape，退出编辑模式且不保存更改
- 给定输入有效快捷键并按下 Enter，新快捷键生效并高亮显示
- 给定在搜索框输入文字，仅显示匹配的快捷键
- 给定点击重置所有按钮，所有快捷键恢复为默认值

### FR-05：通知设置

**描述**：用户可配置系统浏览器通知、应用内提醒和声音提示。

**要求**：

- 系统通知区域显示浏览器通知权限状态，支持启用/禁用和发送测试通知
- 浏览器拒绝通知权限时显示提示信息并禁用相关操作
- 应用内提醒支持启用/禁用应用内 Toast 通知
- 声音设置包含总开关、当前会话也播放开关和音量滑块（0-100）
- 四种通知事件类型各自独立配置音效：完成、权限请求、问题、错误
- 每种事件支持选择内置音效、无声音或自定义音频
- 自定义音频支持上传、预览、导出和删除操作
- 上传音频文件需验证类型（audio/\*）和大小限制
- 音效选择器以按钮组形式呈现，已上传自定义音频时显示自定义选项

**验收标准**：

- 给定启用系统通知并点击发送测试，浏览器弹出测试通知
- 给定浏览器拒绝通知权限，相关操作被禁用并显示提示
- 给定调节音量滑块，数值实时更新并显示
- 给定上传有效音频文件，自定义选项出现在音效选择器中
- 给定上传超过大小限制的文件，显示错误提示
- 给定点击音效预览按钮，播放对应音效

### FR-06：聊天设置

**描述**：用户可配置聊天界面的行为偏好，包括路径格式、自动批准、沉浸模式和显示选项。

**要求**：

- 路径格式支持三种模式：自动检测、Unix 斜杠、Windows 反斜杠，以分段控制器呈现
- 自动模式显示当前检测到的路径风格和实际使用的风格
- 自动批准开关控制是否自动确认所有操作请求
- 后续消息排队开关控制 AI 处理期间用户输入的消息是否排队
- 长消息折叠开关控制用户消息的显示方式
- 沉浸模式开关开启后，自动联动调整内联工具请求、描述性工具步骤、工具卡片样式和紧凑权限提示
- 思考过程显示支持三种样式：胶囊、斜体、Markdown
- 工具卡片样式支持经典和紧凑两种
- 步骤完成信息可独立开关：Token 用量、缓存命中、API 费用、响应时间、总耗时

**验收标准**：

- 给定切换路径格式，聊天界面中的路径显示风格立即变化
- 给定开启沉浸模式，相关子选项自动调整为沉浸模式推荐值
- 给定关闭沉浸模式，之前被联动修改的选项不自动恢复
- 给定切换思考过程显示样式，AI 思考内容的呈现方式发生变化
- 给定开关步骤完成信息项，消息末尾显示或隐藏对应指标

### FR-07：服务设置

**描述**：桌面应用用户可在设置面板中管理本地后端服务的启动、停止和配置。

**要求**：

- 仅在桌面应用环境下显示，浏览器环境显示提示信息
- 支持配置二进制文件路径，带防抖保存
- 自动启动开关控制应用启动时是否自动运行本地服务
- 服务状态显示四种情况：启动中、运行中（由本应用启动）、运行中（外部启动）、未运行
- 支持手动启动、停止和刷新服务状态
- 环境变量以键值对列表形式管理，支持添加和删除
- 启动失败时显示错误信息

**验收标准**：

- 给定在浏览器环境打开设置，服务设置显示"仅桌面端可用"提示
- 给定在桌面环境打开，自动检测并显示当前服务状态
- 给定修改二进制路径，400 毫秒后自动保存
- 给定点击启动按钮，服务启动并更新状态
- 给定添加环境变量，新的键值对输入框出现在列表中
- 给定服务启动失败，显示具体错误信息

### FR-08：设置持久化

**描述**：所有设置变更自动保存到本地存储，刷新页面后恢复上次配置。

**要求**：

- 快捷键配置存储到本地存储，仅保存与默认值不同的项
- 服务器配置存储到本地存储，当前活动服务器同时存储到会话存储和本地存储
- 会话存储用于当前窗口刷新后保持，本地存储用于新窗口继承默认值
- 声音设置存储到本地存储，自定义音频文件存储到 IndexedDB
- 主题和布局设置由各自的状态管理模块负责持久化
- 自定义 CSS 和二进制路径等文本输入采用防抖保存，避免频繁写入

**验收标准**：

- 给定修改快捷键后刷新页面，自定义快捷键保持不变
- 给定添加服务器后关闭并重新打开应用，服务器列表完整恢复
- 给定上传自定义音频后刷新页面，音频文件仍然可用
- 给定在窗口 A 切换服务器，窗口 B 不受影响（会话存储隔离）

## 9. 架构决策记录

### ADR-001：为什么服务设置仅在桌面端显示

**决策**：服务管理标签页仅在 Tauri 桌面应用环境下可见，浏览器环境中隐藏并显示提示信息。

**理由**：

- 本地服务启停依赖 Tauri 的 invoke 命令调用原生能力
- 浏览器环境无法直接操作本地进程
- 浏览器用户通常通过 Docker 或独立进程运行后端服务，不需要在此管理

### ADR-002：为什么快捷键使用 Alt 组合键作为默认值

**决策**：默认快捷键大量使用 Alt 组合键，而非传统的 Ctrl 组合键。

**理由**：

- 浏览器保留了大量 Ctrl 组合键（Ctrl+L 地址栏、Ctrl+O 打开文件、Ctrl+N 新窗口、Ctrl+W 关闭标签等）
- 这些浏览器级快捷键无法被网页覆盖
- Alt 组合键在浏览器中冲突较少，可用性更高

### ADR-003：为什么服务器切换时清理会话状态

**决策**：切换活动服务器时，自动清理当前会话的消息存储状态并导航回首页。

**理由**：

- 不同服务器对应不同的后端实例，会话数据不共享
- 保留旧服务器的会话状态会导致数据不一致
- 导航回首页确保用户从干净的上下文开始与新服务器交互

### ADR-004：为什么自定义音频使用 IndexedDB 而非 localStorage

**决策**：自定义音频文件的二进制数据存储在 IndexedDB 中，配置元数据存储在 localStorage 中。

**理由**：

- localStorage 有 5MB 容量限制，无法存储音频文件
- IndexedDB 支持存储 Blob 对象，容量更大
- 配置元数据（音效选择、音量等）数据量小，适合 localStorage
- 两者分离使配置加载不受音频文件加载影响

### ADR-005：为什么活动服务器同时写入 sessionStorage 和 localStorage

**决策**：当前活动服务器 ID 同时写入 sessionStorage（窗口级隔离）和 localStorage（跨窗口共享）。

**理由**：

- 读取时优先从 sessionStorage 获取，确保当前窗口刷新后保持选择
- 新窗口首次打开时，sessionStorage 为空，回退到 localStorage 继承上次选择
- 多窗口场景下，每个窗口可以独立切换服务器而不互相影响

## 10. 风险与缓解

| 风险                             | 影响                               | 缓解措施                                 |
| -------------------------------- | ---------------------------------- | ---------------------------------------- |
| 浏览器保留快捷键无法被覆盖       | 部分默认快捷键在浏览器中无效       | 默认使用 Alt 组合键避开浏览器保留快捷键  |
| 自定义 CSS 语法错误导致界面异常  | 用户输入错误 CSS 可能破坏界面渲染  | CSS 通过 CSS 变量机制注入，影响范围可控  |
| 自定义音频文件过大占用存储空间   | IndexedDB 中积累过多音频文件       | 单文件 2MB 限制，支持删除和替换          |
| 服务器切换时 SSE 重连失败        | 切换后无法接收实时事件             | 健康检查前置，仅允许在线服务器被选中     |
| 移动端标签栏标签过多导致溢出     | 标签数量增加时横向滚动体验下降     | 标签栏支持横向滚动，当前标签始终可见     |
| 快捷键编辑时捕获到修饰键单独按下 | 单独按下 Ctrl/Alt/Shift 不应被记录 | 编辑模式下忽略纯修饰键的 keydown 事件    |
| 跨域服务器认证信息泄露风险       | 密码通过 Basic Auth 传递           | 显示跨域安全警告，引导用户关注上游 issue |
